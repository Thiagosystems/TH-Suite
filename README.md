# TH-Suite
TH Suite: otimização completa para Windows em um só app. Mais de 80 ajustes explicados e reversíveis (desempenho, jogos, energia, privacidade), limpeza de RAM com modo jogo, limpeza de disco e desinstalador, monitor de hardware e internet para jogos, detecção de vírus e mineradores e 31 reparos do Windows com um clique.
